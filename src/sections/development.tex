\subsection{¿Cuál es la principal función de un sistema operativo?}

El sistema operativo (SO) es un software que sirve a gestionar los recursos de hardware 
y también gestiona aplicativos y procesos. Con él, es posible hacer que el hardware
trabaje de forma coordinada. Sin el sistema operativo, el hardware no habría la capacidad de ejecutar
aplicativos, tal como juegos y programas, para el usuario. 

\subsection{¿Qué caracteriza un proceso en un sistema operativo?}
Quiere casi decir, ¿qué hace un proceso? Que yo sepa, un proceso realiza actividades a cuál
fue programado para hacer. Puede, por ejemplo, editar un programa o un sistema de archivos, 
puede ser también un juego. Pero, para contestar a esta pregunta, tenemos que ver las opciones disponibles
que el profesor ha dado. Para las preguntas, la contestación más precisa sería la "b)".
Un programa en ejecución con su propio espacio de memoria. Lo que quiere decir, que además
de ejecutar instrucciones binarias, también tiene en su interior una abstracción de la memoria del ordenador,
y piensa que detiene toda la RAM. Pero eso es, en realidad, una ilusión.

El \href{https://www.lenovo.com/es/es/glossary/process/}{Sítio web de Lenovo} dice que un proceso se refiere
a la ejecución de un programa o una tarea en un sistema informático. Todo proceso posee una cantidad
específica de recursos del sistema a utilizar, y eso decide el sistema operativo. (Tiempo de la unidad central de procesamiento, memoria y dispositivos de entrada y salida).
El proceso, de esa manera, se ejecuta en su propio espacio de direcciones virtual y ejecuta las instrucciones especificadas en su código de programa.
Mi idea era buena, y necesitaba solamente estos detalles, específicamente, que a un proceso son dados recursos de sistemas de acuerdo con la necesidad. 

\subsection{¿Cuál es la diferencia entre un proceso y una thread?}
Un proceso, como dicho antes, es una tarea o un conjunto de instrucciones que pueden ser ejecutados dentro de la memoria virtual.
Una thread es otra cosa, es como una división del procesador que permite que multiplas tareas dentro de un proceso sean ejecutadas al mismo tiempo.
