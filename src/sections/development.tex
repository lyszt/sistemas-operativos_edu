\subsection{¿Cuál es la principal función de un sistema operativo?}

El sistema operativo (SO) es un software que sirve a gestionar los recursos de hardware 
y también gestiona aplicativos y procesos. Con él, es posible hacer que el hardware
trabaje de forma coordinada. Sín el sistema operativo, el hardware no habría la capacidad de ejecutar
aplicativos, tal como juegos y programas, para el usuario.
